# 구현 세션 시작 프롬프트

`D:\01_Developement\yt-loader-android`에서 Claude Code를 열고 아래 중 하나를 붙여넣는다.

## 첫 세션

```
YTLoader 데스크톱 앱(yt-dlp 기반 YouTube 다운로더)의 Android 버전을 이 폴더에서 새로 만들 거야.
설계는 끝났고 문서로 정리돼 있어. CLAUDE.md, docs/SPEC.md, docs/ARCHITECTURE.md, docs/PLAN.md를 읽고
PLAN.md의 첫 번째 미완료 마일스톤부터 진행해 줘.

진행 방식:
- 아직 git 저장소가 아니면 먼저 git init 하고, ARCHITECTURE.md 13장의 .gitignore를 만든 뒤
  지금 있는 문서와 함께 첫 커밋으로 남겨 줘.
- 마일스톤마다 완료 조건을 실제로 검증하고, PLAN.md를 갱신하고, 커밋한 뒤 다음으로 넘어가.
- ⏸ 지점(환경 설치 승인, M1 측정 결과, M5 계정 로그인 검증, M6 라이선스·키스토어)에서는 멈추고 보고해 줘.
  내가 결정하거나 직접 해야 하는 일이라서야.
- 문서의 [확인 필요] 항목은 추측하지 말고 라이브러리 소스나 공식 문서로 확인한 뒤 문서를 고쳐 줘.
  이 문서는 2026-10-31 기준 조사로 만들어서 그 사이 바뀐 게 있을 수 있어.
- 설계와 다르게 가야 할 이유를 발견하면 구현하기 전에 알려 줘.

보고는 짧게: 무엇을 했는지, 증거(테스트 결과·명령 출력·스크린샷 경로), 내가 결정하거나 해 줘야 할 것.
작업이 길어져도 괜찮아. 컨텍스트는 자동으로 압축되고, 진행 상황은 PLAN.md에 남아 있으니까.
```
